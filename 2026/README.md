## Экзамен / Коллоквиум.

Экзаменом на курсе является коллоквиум - теоретический опрос. Коллоквиум проводится на сессионной неделе.
Проводится без подготовки примерно 10-15 минут на студента, чтобы оценить понимание теоретической основы языка:
2 простых вопроса + 2 средних вопроса + 2 сложных вопроса + доп вопросы.

Простой вопрос дает 0.5 баллов, средний вопрос дает 1 балл, сложный вопрос даёт 2 балла и 3 дополнительных вопроса по одному баллу.
[Пул вопросов](https://github.com/DanielShinoda/ami_python_25_lectures/tree/main/colloquium) будет предоставлен за несколько недель до коллоквиума. Дополнительные вопросы не будут предоставлены для подготовки.

На экзамене нельзя пользоваться ноутбуком или какими-либо другими заготовленными материалами с полезной информация для ответа.

В качестве пересдачи соответственно коллоквиум. При этом коллоквиум неблокирующий.

### Правила / формула оценивания.

---

```Итоговая оценка = 0.2 * О_Семинары + 0.5 * О_ДЗ + 0.3 * О_Экзамен```

* `О_Семинары` - работа на семинарах (на усмотрение семинариста);
* `О_ДЗ` - средняя оценка за домашние задания (2 штуки);
* `О_Экзамен` - оценка за экзамен / коллоквиум.

---

Округление оценки - округляется только итог. Округление арифметическое, блокирующих оценок нет.

Домашние задания выдаются для самостоятельного выполнения в ipynb-файлах. Всего будет 2 домашних задания по курсу.

Каждое домашнее задание имеет 1 дедлайн: жесткий. Задания выдаются примерно на 10 дней. После жесткого дедлайна задачи не оцениваются.

Правила оценивания семинаров выбираются самими семинаристами и проставляются ими же.
